When you bookmark or select "Add to Home Screen" on your mobile phone, the device uses the configured HTML metadata to identify what graphic and title to render. You can customize this file directly in three easy steps:

  1. Prepare Your Custom Image: Create or find a square graphic. Recommended dimensions are 180x180 pixels for mobile screens and 32x32 pixels for standard browser tabs.
  2. Host the File: Upload your custom graphic to a reliable hosting service (like Imgur, Postimages), or save it in your local folder if self-hosting.
  3. Edit HTML Source: Open this file in any text editor. Look at the topmost <head> tags and replace the sample placeholder links in the following lines: 
    <!-- Mobile Home Screen Icon -->
<link rel="apple-touch-icon" href="YOUR_IMAGE_URL_HERE">

<!-- Browser Tab Icon -->
<link rel="icon" type="image/png" href="YOUR_FAVICON_URL_HERE">
To Add on Your Mobile Device:

iOS Safari: Tap the Share Button (square with up arrow), scroll down, and select "Add to Home Screen".
Android Chrome: Tap the three dots menu icon, then select "Add to Home screen".
